启动方式

交付 ZIP 内带本次新构建的 dist。安装 Python 3 后，Windows 双击“启动旅游.bat”，macOS 双击“启动旅游.command”，或执行“python 启动旅游.py”，访问 http://127.0.0.1:8901/。源码开发执行 npm ci、npm run dev（Node.js 20.19+ 或 22.12+）。
