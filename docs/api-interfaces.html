# 旅游规划契约 - 输入：浏览器表单与 URL city/from/d/b/p/s/pace/m/prefs/t/start/spots/only。天数1..15、人数1..10、预算1000..80000；非法 URL 使用默认值。空 prefs/start 可显式表达无偏好/未设日期；only 状态独立于当前是否选点。 - 有效 start 日期优先决定月份；表单月份更改会同步日期并夹到目标月末；输入日期同步月份。 - 本地引擎输出 TripPlan（逐日景点、三餐、路线、预算与提示），不依赖其他本仓库服务。 - 日期导出仍为 ICS，UID 增加目的地和景点/餐点身份以避免跨目的地覆盖。 - 可选天气/图片/地理位置查询保持原接口，失败降级，不阻塞基础行程。 - 可选 AI：浏览器直连用户选择的 HTTP/HTTPS 端点，JSON 协议保持原格式；请求最多90秒，调用者 AbortSignal 与超时信号合并。更换行程/城市或移除配置后不接受旧结果。 - AI 配置变动通过同页事件同步，存储不可用时保留会话内配置。在线验证脚本只从本项目 local-secrets/api-keys/ai.json 读取显式配置，不读取其他软件令牌。 - 交付 dist 是静态产物，通过 Python 启动旅游.py 默认在 127.0.0.1:8901 提供；启动失败返回非零状态。源码通过 npm ci 安装本目录依赖。 - API 错误会显示/降级，真实第三方服务、票价与开放时间不由此契约保证。
